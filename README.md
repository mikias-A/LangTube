# LangTube

A web app built mainly on JavaScript, Python/Flask and p5.js that takes a YouTube video and displays clickable captions alongside it. Clicking any word shows its translation and dictionary definition in your target language.

**Target languages:** Spanish, Korean, Chinese, English

## Prerequisites

- Python 3.x
- A web browser

## Setup

```bash
git clone https://github.com/bob-R/langtube.git
cd langtube
pip install -r requirements.txt
```

## Run

Run python server.py in your terminal then open http://localhost:8000 in your browser.

## Stop

Hit Ctrl+C in your terminal then close the browser tab.
