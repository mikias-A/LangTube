# LangTube

A web app built mainly on JavaScript, Python/Flask and p5.js that takes a YouTube video and displays clickable captions alongside it. Clicking a word shows its translation and dictionary definition in your target language.

**Target languages:** Spanish, Korean, Chinese, English

## Prerequisites

- Python 3.x
- A web browser

## Setup

```bash
git clone https://github.com/mikias-A/langtube.git
cd langtube
